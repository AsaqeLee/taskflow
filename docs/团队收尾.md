## 维护模式约定

1. **默认只做：** bug 修复、安全补丁、依赖小版本、文档与脚本与实现不一致时的修正。
2. **新开功能：** 需单独立项；避免与后端状态机、发布门禁假设冲突。
3. **本地跑栈：** `bash scripts/compose_smoke.sh`（需本机 Docker/Colima 已启动）。
4. **密钥：** `.env` 仅本地，勿提交；试点/生产用 `scripts/init_pilot_env.sh` 或按 `DEPLOYMENT.md` 在目标机生成。
