# 前端窄屏 / 移动端验收清单

在宽度 **375px**（iPhone SE）与 **768px**（平板）下各测一遍。使用 `web npm run dev` + 浏览器开发者工具设备模拟。

## 登录 `/login`

- [ ] 表单不横向溢出
- [ ] 输入框可聚焦、键盘不遮挡提交按钮
- [ ] 错误提示完整可见

## 任务列表 `/tasks`

- [ ] 「新建任务」按钮可点击
- [ ] 表格在小屏可横向滚动或换行可读（标题列优先）

## 新建任务 `/tasks/new`

- [ ] 标题/描述输入可用
- [ ] 创建成功后跳转详情

## 任务详情 `/tasks/:id`

- [ ] 状态 Stepper 换行不重叠
- [ ] **分配**：下拉与按钮在竖屏下纵向排列（`TaskActionsBar` flex-col）
- [ ] 动作按钮不挤出屏幕
- [ ] 删除/提交等 **弹窗** 居中、可滚动、可关闭
- [ ] 记录/审计 Tab 可切换

## 权限提示

- [ ] 无可用操作时显示「当前状态下你没有可执行的操作」

## MVP 范围外（确认未实现）

- [ ] 无用户管理页
- [ ] 无密码重置页
- [ ] 无注册页（`ALLOW_PUBLIC_REGISTER=false`）
